# Braemac Display Offering

A touch-first, offline-friendly kiosk experience for exploring Braemac commercial displays, media-player platforms and display technology.

## Run locally

Open `index.html` directly, or serve this folder with any static web server:

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.

On Windows, double-click `Launch-Braemac-Display-Kiosk.cmd` to open the local app in Chrome full-screen when Chrome is available. The app and bundled datasheets do not require an internet connection.

## Kiosk controls

- Use the four main cards or the header to navigate.
- The top-right controls switch theme and enter full screen.
- The attract screen starts after 60 seconds without interaction.
- All datasheets are bundled under `assets/datasheets`.
